## Description

Tired of switching apps for every database? DBDeck is a free, open source database client for VS Code and Cursor. PostgreSQL, MySQL, ClickHouse, BigQuery, Snowflake, MongoDB, Redis, Elasticsearch, S3 and Docker in one sidebar, right next to your code.

🔗 Install: https://dbdeck.dev
⭐ Source: https://github.com/jurasw/dbdeck

What you get:

- **All your connections in one place.** Group them as Local, Staging and Production and open any table in a click.
- **Omnisearch.** Find any table, view, function or value across a database in a few keystrokes.
- **AI filter.** Type "paid orders from Poland over 100" and get a ready WHERE clause. Review it, then click Apply.
- **AI query.** Describe what you need. AI reads your schema and writes SQL that you can review and run. Works with ChatGPT, an OpenAI or Claude API key, or local Ollama.
- **Schema diagram.** See your tables and how they connect, drawn for you.
- **Beyond SQL.** Browse and edit Redis keys, MongoDB documents and Elasticsearch indexes.
- **Private by design.** Passwords stay in your OS keychain. No telemetry, no analytics, no cloud sync. AI agents get read-only access over a local MCP server.

Free forever. MIT licensed. No account. No paywall.

Install in a minute:

- VS Code: open Extensions, search for **DBDeck**, click Install
- Cursor, VSCodium, Windsurf: same search, installs from Open VSX
- Terminal: `code --install-extension dbdeck.dbdeck`
