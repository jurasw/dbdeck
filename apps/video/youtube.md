## Description

DBDeck is a free, open source database client for VS Code and Cursor. postgres, mysql, clickhouse, bigquery, snowflake, mongodb, redis, elasticsearch, s3 and docker, all in your editor sidebar. browse tables, search, write SQL, ask AI for queries and filters, see your schema as a diagram
